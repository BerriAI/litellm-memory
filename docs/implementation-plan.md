# litemem implementation plan

The authoritative plan is now the [litemem product and implementation specification](product-implementation-spec.md).

It replaces this earlier draft and incorporates the full product feedback, including the single progressive setup surface, LiteLLM-only inference credentials, required TypeSafe/Jev checks, separate embedding/web/Slack model settings, historical migration, privacy boundaries and completion criteria.

Use that specification for implementation. Its final sections distinguish verified current state from the work remaining; the full product is not yet deployed.
